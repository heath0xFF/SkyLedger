SkyLedger Raspberry Pi Setup Guide

This guide walks you from a blank Raspberry Pi to a self-starting SkyLedger flight dashboard on a TV or monitor. It is written for someone who is comfortable following recipes, not someone who already knows Linux.

Estimated time: 60 to 120 minutes No paid cloud account needed Copy and paste friendly

What You Are Building

You are setting up a small computer, the Raspberry Pi, to listen for airplane signals with a USB radio receiver. SkyLedger reads those nearby airplane positions and shows them on a dashboard that can stay open on a TV.

When It Is Done

  • The Pi turns on by itself.
  • The airplane receiver starts by itself.
  • SkyLedger starts by itself.
  • The TV opens the SkyLedger dashboard full screen.
  • The Pi periodically checks that the receiver and dashboard are still running.

How To Use This Page

  • Do the steps in order.
  • Copy commands exactly from the dark boxes.
  • Replace anything in angle brackets, like <your_latitude>, with your own value.
  • Stop at each green checkpoint before moving on.

Hardware And Requirements

Required Hardware

  • Raspberry Pi 4 Model B.
  • Official-style USB-C power supply for the Pi.
  • 32 GB or larger microSD card.
  • microSD card reader for your normal computer.
  • micro-HDMI to HDMI cable.
  • TV or monitor for the dashboard.
  • USB keyboard and mouse for first setup, even if you remove them later.
  • ADS-B USB receiver for 1090 MHz aircraft signals.
  • 1090 MHz antenna.

Recommended Receiver

Use an ADS-B-friendly RTL-SDR receiver. Good choices are usually based on an R820T or R820T2 tuner, such as a FlightAware Pro Stick, RTL-SDR Blog dongle, or standard NooElec NESDR SMArt.

The NooElec NESDR SMArt XTR may work, but it can be weak for ADS-B. If SkyLedger works but sees very few planes, the receiver or antenna placement is the first thing to suspect.

Network Requirements

  • Your Pi needs internet access during setup.
  • Ethernet is easiest and most reliable.
  • Wi-Fi also works if you enter the Wi-Fi name and password while preparing the card.
  • Your normal computer and Pi should be on the same home network.

Accounts And Downloads

  • Raspberry Pi Imager on your normal computer.
  • The SkyLedger GitHub repository must be public, or the Pi must have private access to it.
  • Your home latitude and longitude in decimal form, such as 41.000000 and -87.000000.
Privacy note Your latitude and longitude are your receiver location. Keep the real values out of screenshots, public examples, and public files.

Before You Start

1

Prepare The microSD Card

This puts Raspberry Pi OS on the card, sets the Pi name, turns on remote access, and saves your Wi-Fi details if needed.

  1. Install and open Raspberry Pi Imager on your normal computer.
  2. Insert the microSD card into your normal computer.
  3. In Raspberry Pi Imager, choose Raspberry Pi 4 as the device.
  4. Choose Raspberry Pi OS (64-bit) with Desktop. Do not choose Lite; the TV dashboard needs the desktop browser.
  5. Choose your microSD card as the storage device.
  6. Open the settings or customization screen before writing the card.
  7. Set the hostname to skyledger-pi.
  8. Set the username to pi.
  9. Choose a strong password and write it somewhere safe.
  10. If using Wi-Fi, enter your Wi-Fi name and password.
  11. Set your country, timezone, and keyboard layout.
  12. Turn on SSH.
  13. Write the card. When it finishes, eject it safely.
Checkpoint You should have a finished microSD card with Raspberry Pi OS on it.
2

Start The Pi

This is the physical setup: card, screen, network, receiver, antenna, then power.

  1. Put the microSD card into the Pi.
  2. Connect the Pi to the TV or monitor with HDMI.
  3. Connect the keyboard and mouse.
  4. Connect Ethernet if you are using it.
  5. Plug the ADS-B receiver into the Pi.
  6. Attach the antenna to the receiver.
  7. Place the antenna near a window or as high as practical.
  8. Plug in the Pi power supply.
  9. Wait for the desktop to appear. The first boot can take several minutes.
Checkpoint The Pi desktop is visible on the screen, or the Pi is online and reachable from your normal computer.
3

Connect To The Pi

The easiest setup is to control the Pi from your normal computer. If that does not work, you can run the same commands in Terminal directly on the Pi.

From Windows

Open PowerShell from the Start menu and run this:

ssh pi@skyledger-pi.local

From Mac

Open Terminal and run this:

ssh pi@skyledger-pi.local

If it asks whether you trust the computer, type yes and press Enter. Then enter the Pi password you chose earlier. The password will not appear while you type; that is normal.

If the name does not work Find the Pi address in your router, then use ssh pi@<pi-ip-address>. Example: ssh pi@192.168.1.42.
4

Update The Pi

This updates the Pi and installs the basic tools SkyLedger needs.

Paste this whole block into the Pi Terminal, then press Enter:

sudo apt update
sudo apt -y full-upgrade
sudo apt install -y git python3-venv python3-pip rsync curl wget
command -v chromium || command -v chromium-browser || sudo apt install -y chromium-browser
sudo raspi-config nonint do_blanking 1
sudo reboot

The Pi will restart. Wait about two minutes, then reconnect:

ssh pi@skyledger-pi.local
Checkpoint You are connected to the Pi again after the restart.
5

Install The Plane Receiver Software

SkyLedger does not talk directly to the USB receiver. Another program listens to the receiver and writes a small live aircraft file for SkyLedger to read.

Install the receiver program:

sudo bash -c "$(wget -O - https://github.com/wiedehopf/adsb-scripts/raw/master/readsb-install.sh)"
sudo reboot

After the Pi restarts, reconnect:

ssh pi@skyledger-pi.local

Now tell the receiver where your antenna is. Replace the placeholders with your real decimal latitude and longitude:

sudo readsb-set-location <your_latitude> <your_longitude>
sudo readsb-gain auto

Install the local airplane map:

sudo bash -c "$(wget -nv -O - https://github.com/wiedehopf/tar1090/raw/master/install.sh)"
Checkpoint The receiver software and local airplane map are installed.
6

Check The Receiver

This confirms the Pi can see the aircraft receiver output before SkyLedger is installed.

Run these checks:

systemctl status readsb --no-pager
ls -l /run/readsb/aircraft.json
curl http://127.0.0.1/tar1090/data/aircraft.json

What you want to see:

  • The first command should say active or running.
  • The second command should show a file named aircraft.json.
  • The third command should print a block of text with words like now, messages, or aircraft.

From your normal computer, try opening this page:

http://skyledger-pi.local/tar1090
If you see no planes yet That can be normal indoors or during quiet air traffic. The important part is that the receiver service is running and the aircraft file exists.
7

Install SkyLedger

This downloads SkyLedger, installs what it needs, and sets it up to run automatically.

Download SkyLedger from GitHub:

cd ~
git clone https://github.com/cjs007/SkyLedger.git
cd ~/SkyLedger
git checkout main
chmod +x install.sh scripts/pi-healthcheck.sh scripts/skyledger-update.sh
If GitHub says the repository was not found The repository is probably still private or the URL is different. Make the repository public first, or update the command to use the correct repository address.

Install SkyLedger and its automatic background helpers:

cd ~/SkyLedger
INSTALL_SERVICE=1 INSTALL_HEALTHCHECK=1 INSTALL_UPDATE_SERVICE=1 ./install.sh

This may take a few minutes. It is finished when the Terminal returns to a prompt where you can type again.

Checkpoint SkyLedger is installed, and the automatic startup helpers are enabled.
8

Add Your Location To SkyLedger

SkyLedger needs your receiver location so it can show distances and decide what counts as a nearby aircraft.

Open the SkyLedger settings file:

sudo nano /etc/skyledger/config.yaml

In the editor, change or add these lines. Replace the latitude and longitude placeholders with your real values:

home_lat: <your_latitude>
home_lon: <your_longitude>
home_name: "Home Base"
dashboard_title: "SkyLedger"
adsb_json_path: "http://127.0.0.1/tar1090/data/aircraft.json"
database_path: "skyledger.db"
dashboard_port: 8000
tar1090_url: "http://localhost/tar1090/"
tracking_radius_miles: 0.0

Allow the SkyLedger web settings page to save changes to this file:

sudo chown pi:pi /etc/skyledger /etc/skyledger/config.yaml
sudo chmod 750 /etc/skyledger
sudo chmod 640 /etc/skyledger/config.yaml

How To Save In Nano

  1. Press Ctrl and O at the same time.
  2. Press Enter to confirm the file name.
  3. Press Ctrl and X at the same time to leave the editor.
Checkpoint Your real latitude and longitude are saved in /etc/skyledger/config.yaml on the Pi.
9

Start SkyLedger

This starts the dashboard and checks that it can talk to the receiver.

Run this:

sudo systemctl start skyledger
sudo systemctl status skyledger --no-pager
curl http://127.0.0.1:8000/api/status

What you want to see:

  • The status command should say active or running.
  • The final command should print SkyLedger status text.
  • If the receiver is healthy, the status text should include receiver_online with a true value.

From your normal computer, open:

http://skyledger-pi.local:8000
Checkpoint The SkyLedger dashboard opens in a browser.
10

Make The Dashboard Open Full Screen

This makes the Pi act like a dedicated TV dashboard after it turns on.

Create the startup file:

mkdir -p ~/.config/labwc
nano ~/.config/labwc/autostart

Paste this one line into the file:

sh -c 'chromium http://127.0.0.1:8000 --kiosk --noerrdialogs --disable-infobars --no-first-run --enable-features=OverlayScrollbar --start-maximized || chromium-browser http://127.0.0.1:8000 --kiosk --noerrdialogs --disable-infobars --no-first-run --enable-features=OverlayScrollbar --start-maximized' &

Save the file with Ctrl + O, Enter, then Ctrl + X.

Now turn on automatic desktop login:

sudo raspi-config
  1. Choose System Options.
  2. Choose Boot / Auto Login.
  3. Choose Desktop Autologin.
  4. Exit the menu.

Restart the Pi:

sudo reboot
Checkpoint After the restart, the Pi should open SkyLedger full screen on the connected display.

Final Check

Useful Pages

  • SkyLedger dashboard: http://skyledger-pi.local:8000
  • Receiver map: http://skyledger-pi.local/tar1090
  • SkyLedger settings page: http://skyledger-pi.local:8000/settings

Troubleshooting

I cannot connect to skyledger-pi.local

  • Make sure the Pi is powered on.
  • Make sure the Pi is on the same network as your computer.
  • Look for the Pi address in your router, then use ssh pi@<pi-ip-address>.

SkyLedger opens, but the receiver is offline

Run this on the Pi:

systemctl status readsb --no-pager
curl http://127.0.0.1/tar1090/data/aircraft.json
curl http://127.0.0.1:8000/api/status

If the receiver file is missing, restart the receiver:

sudo systemctl restart readsb

The dashboard works, but I see no planes

  • Move the antenna closer to a window or higher up.
  • Wait 10 to 20 minutes.
  • Open http://skyledger-pi.local/tar1090 and see whether the receiver map sees anything.
  • If tar1090 has aircraft but SkyLedger does not, set adsb_json_path to http://127.0.0.1/tar1090/data/aircraft.json in /etc/skyledger/config.yaml.
  • If you are using an XTR receiver and results stay poor, try an ADS-B-friendly R820T or R820T2 receiver.

The full-screen browser opens before SkyLedger is ready

  • Wait a few seconds and refresh the page with Ctrl + R.
  • If it keeps happening, run sudo systemctl status skyledger --no-pager to check SkyLedger.

I want to manually update SkyLedger later

If you push a new version to GitHub and want the Pi to update now, run:

sudo systemctl start skyledger-update.service
journalctl -u skyledger-update.service -n 100 --no-pager

When To Ask For Help

Ask for help with the exact screen or command output if one of these happens:

  • A command says not found.
  • A command says permission denied.
  • GitHub says the repository does not exist.
  • The receiver never creates /run/readsb/aircraft.json.
  • SkyLedger does not open at http://skyledger-pi.local:8000.
